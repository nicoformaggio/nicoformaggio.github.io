About

Hello, I am Nico. I am a Game Designer and Programmer but my main area of work is in Technical Design. I got into games very early into my childhood with my first game console bring the Nintendo 64. Playing games from a very early age really got me excited and passionate about the world of video games and it was at a young age (around 7) that I knew I wanted to work in the industry of games.

While I have been using computers and learning IT skills from a very young age it was at 15 that I started to learn programming and getting more into software and hardware with regards to IT work. I started properly learning code at Aylesbury College where I learnt C# code to tackle various problems and solve them by utilising problem solving skills alongside C# skills. I then made my first game Bucky-Ball in the 2nd year of College and passed my course with a triple distinction.

I now study at Staffordshire University on the Computer Games Design and Programming course where I am on my third and final year. Below are many examples of my work at University, some being group projects and they are labeled accordingly to what engine I used and any programming languages I used. I also designed and created this website using Bootstrap

If you have any questions. Feel free to contact me via the contact me section and I will be sure to get back to you as soon as possible :)

Bucky Ball

Video

Screenshots

Previous Next

This game is a rolling ball platformer and the objective of this game is to collect each of the pickups scattered around the level and that will unlock the finish so that you can proceed to the next level.

This is my first game that I have made. I made this for a unit at college for the BTEC Level 3 Exdended Diploma in IT course. This game was made using the game engine Unity and everything in the game was developed by me (apart from a couple assets like the skybox and a couple of the sounds).

Certain skills that I have used in making this game involves use of C# for all of the scripts in the Unity engine for this game, I have also used design skills to come up with the initial idea and to fully plan and develop the game and levels. Basic 3D Modelling was also used to create the levels and I used Sketchfab to model these.
