Bucky Ball

Video

Screenshots

Previous Next

Status: Beta

This game is a rolling ball platformer and the objective of this game is to collect each of the pickups scattered around the level and that will unlock the finish so that you can proceed to the next level.

This is my first game that I have made. I made this for a unit at college for the BTEC Level 3 Exdended Diploma in IT course. This game was made using the game engine Unity and everything in the game was developed by me (apart from a couple assets like the skybox and a couple of the sounds).

Certain skills that I have used in making this game involves use of C# for all of the scripts in the Unity engine for this game, I have also used design skills to come up with the initial idea and to fully plan and develop the game and levels. Basic 3D Modelling was also used to create the levels and I used Sketchfab to model these.
